# prince776.github.io

Personal site and blog, built by GitHub Pages with Jekyll.

## Writing a post

Add a Markdown file to `_posts/` named `YYYY-MM-DD-slug.md`:

```markdown
---
layout: post
title: "Post title"
description: "One-line summary, used for previews and SEO."
---

Body in Markdown. Fenced code blocks get syntax highlighting.
```

Push to `main` and it is live at `/blog/slug/` within a minute.

- Drafts: put them in `_drafts/` (not published).
- Writing on other sites: add an entry to `_data/elsewhere.yml`.
- RSS feed: `/feed.xml`.
